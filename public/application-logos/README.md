# Application logos

Local brand artwork used to identify the applications in the capabilities profile.
Source URLs are recorded in sources.json. VS Code, WordPress, Shopify, Wix and
Microsoft product icons were obtained from their official hosts. Other marks use
LobeHub Icons, Devicon and Simple Icons artwork where official downloads were
unavailable. Trademarks belong to their respective owners; no endorsement is implied.

The showcase uses monochrome contrast treatment for ChatGPT, Codex, WordPress and
DaVinci Resolve on charcoal. The compact details use original artwork. All visible
names and descriptions come from app/capabilities/profile-data.ts.

Motion: 25 CSS pixels/second, measured per repeat group. Desktop rows loop in
opposite directions without pointer/focus pauses. Mobile and reduced motion use
a static grid. Rendering pauses offscreen and when the browser tab is hidden.
